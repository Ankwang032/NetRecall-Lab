# IP 주소와 서브넷

IPv4 주소는 32비트 논리 주소이며, 네트워크 부분과 호스트 부분으로 나뉜다.
어디까지가 네트워크 부분인지는 서브넷 마스크(또는 CIDR 접두사 길이)가 정한다.

예: `192.168.10.25/24`

- 서브넷 마스크: `255.255.255.0`
- 네트워크 주소: `192.168.10.0` (호스트 비트가 모두 0)
- 브로드캐스트 주소: `192.168.10.255` (호스트 비트가 모두 1)
- 사용 가능한 호스트 주소: `192.168.10.1` ~ `192.168.10.254` (254개)

## 같은 네트워크인지 판단하기

출발지 호스트는 목적지 IP와 자신의 서브넷 마스크를 AND 연산해 네트워크 주소를 비교한다.

- 같으면 같은 네트워크다. ARP로 목적지 MAC 주소를 찾아 직접 보낸다.
- 다르면 다른 네트워크다. 기본 게이트웨이(라우터)로 보낸다.

## 질문

- 10.0.5.130/26 이 속한 네트워크 주소, 브로드캐스트 주소, 사용 가능한 호스트 수를 구하세요.
- 같은 스위치에 연결된 두 호스트의 서브넷 마스크가 서로 다르게 설정되면 어떤 문제가 생길 수 있나요?
- 출발지 호스트는 목적지가 같은 네트워크에 있는지 어떻게 판단하며, 판단 결과에 따라 프레임을 어디로 보내나요?
